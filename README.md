# ♻️ CleanRoute

CleanRoute is a smart waste collection management system designed to
help cities monitor waste bins, identify critical bins, report waste
problems, and generate efficient collection routes.

## 🚀 Features

- 📊 Waste collection dashboard
- 🗑️ Real-time-style bin monitoring
- 🚨 Critical and high-priority bin detection
- 📝 Citizen waste reporting
- 🚛 Smart collection route generation
- 📱 Responsive design

## 💡 Problem

Traditional waste collection can result in unnecessary trips,
overflowing bins, and inefficient collection routes.

## 💡 Solution

CleanRoute monitors bin fill levels and helps collection teams
prioritize bins that require attention.

## 🛠️ Technologies

- HTML
- CSS
- JavaScript

## 📊 Bin Monitoring

The system classifies bins according to their fill level:

- 90% or above → Critical
- 70–89% → High
- Below 70% → Normal

## 🚛 Smart Routing

CleanRoute identifies bins requiring collection and generates a
suggested collection route.

## 📝 Citizen Reporting

Citizens can report waste problems such as overflowing or damaged
bins.

## 🎯 Hackathon Project

CleanRoute was developed as a prototype for a hackathon to demonstrate
how technology can improve urban waste collection.
